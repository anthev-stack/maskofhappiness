maskofhappiness.com on Vultr
============================

This VPS already uses 3000–3004. This site binds to 3005.
Port 80/443 is owned by Caddy, not nginx. Do not run certbot --nginx here.

Everyday workflow
-----------------
On this PC:
  git add -A
  git commit -m "your message"
  git push origin main

On the VPS (SSH in as root):
  bash /var/www/maskofhappiness/deploy/update.sh

First install
-------------
1. Point DNS A records for maskofhappiness.com and www to the VPS IP.
2. git clone https://github.com/anthev-stack/maskofhappiness.git /var/www/maskofhappiness
3. bash /var/www/maskofhappiness/deploy/first-install.sh
4. Append deploy/caddy-site.caddy to /etc/caddy/Caddyfile (or import it), then:
     systemctl reload caddy
5. If nginx was started by mistake and other sites broke:
     systemctl stop nginx
     systemctl disable nginx
     systemctl start caddy

The SQLite database and uploaded photos live on the server (prisma/prod.db and
public/uploads). They are not in git, so do not delete the app folder when updating.
